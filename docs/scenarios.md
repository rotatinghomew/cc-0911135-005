# 业务演练

|情景|源站或队列变化|观察结果|
|---|---|---|
|资源竞争|large 连续入队且 small 有待办|small 在所声明公平界限内获得执行机会|
|并行|两个主机都可执行|同时满足全局和主机限制，不退化为全串行|
|主机间隔|同主机多个任务|发起时刻满足 minIntervalMs|
|robots|访问 /private、/private/public、/same|分别拒绝、允许、允许；不是先匹配就返回|
|冷却|coolOnce=true|后续同源请求推迟，其他主机继续，等待不占全局槽|
|日期冷却|dateHeader=true 并注入对应时钟|HTTP 日期和秒数得到一致时钟语义|
|跨站跳转|/redirect|目标重新经过自身策略，不借用原主机额度|
|重启及取消|旧工作仍有租约|恢复前先处理租约和结果，取消未执行请求不发起|
